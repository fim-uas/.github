Espacio de colaboración académica y tecnológica de la **Facultad de Ingeniería Mochis**, perteneciente a la **Universidad Autónoma de Sinaloa**.

Aquí compartimos proyectos, herramientas y recursos relacionados con la ingeniería, el desarrollo de software, la docencia y la investigación. Este espacio busca facilitar el aprendizaje práctico y la colaboración entre estudiantes, docentes y comunidad.
